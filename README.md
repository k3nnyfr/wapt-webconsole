# wapt-webconsole

Console web pour serveur [WAPT](https://www.wapt.fr) **Discovery** : inventaire des machines, actions à distance, affectation de paquets et de groupes, import depuis le store. Utilisable sur ordinateur, tablette et mobile Android, sans `waptconsole.exe`.

> Projet en cours de conception, dépôt privé.
